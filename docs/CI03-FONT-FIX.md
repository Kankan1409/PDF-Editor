# CI.03: ฟอนต์แยกชุดไทย/อังกฤษ

ตรวจไฟล์ส่วนตัว CI.03 วันที่ 15 ตุลาคม 2026: THSarabunPSK ฝังแยกเป็น subset ไทยและอังกฤษ ตัว s มีในชุดอังกฤษ แต่ไม่มี subset ใดมี glyph ครบสำหรับทั้งบรรทัด จึงถูกปฏิเสธในรุ่นก่อน

ปรับให้รวม subset ชื่อฟอนต์เดียวกันเมื่อสิทธิ์อนุญาต หน่วย ขนาด และ glyph ที่ซ้ำกันมีเส้นโครงร่างและ advance/sidebearing ตรงกัน ตรวจผลรวมอีกครั้งว่าเส้นโครงร่างเดิมไม่เปลี่ยน ถ้าไม่ตรงจะปฏิเสธ ไม่ใช้ฟอนต์ชื่อคล้ายกัน

รองรับ Unicode mapping ของวรรณยุกต์จาก AAT morx contextual substitutions เพิ่มจาก GSUB เดิม การรวมฟอนต์ไม่ได้เก็บตาราง AAT ทั้งหมด จึงส่งต่อความหมาย Unicode โดยจับคู่ glyph ที่มีโครงร่างและ metrics เดิม และยังตรวจข้อความอ่านกลับก่อนบันทึก วิธีนี้ไม่ได้รับประกัน layout ของฟอนต์ AAT ทุกชนิด

เพิ่มการค้นหาฟอนต์ที่ติดตั้งเฉพาะผู้ใช้ Windows ด้วย

ทดสอบกับ CI.03 จริง: เพิ่ม ss ในบรรทัดชื่อ ใช้ THSarabunPSK ขนาด สี baseline เดิม แก้ซ้ำได้ ส่งออกและอ่านกลับถูกต้อง พิกเซลนอกบริเวณแก้ (เผื่อขอบ antialias 2px) และหน้าอื่นเหมือนเดิม ตรวจภาพ render แล้ว Backend regression suite ผ่าน 30 รายการ รวม CI.08 ส่วน UI ในเบราว์เซอร์ที่ผู้ใช้เปิดอยู่ยังไม่ได้ทดสอบโดยตรง

ต้องเริ่ม Backend ใหม่เพื่อโหลด Python ที่แก้ไข การกดรีเฟรชหน้าเว็บอย่างเดียวไม่อัปเดต Backend ที่รันโดยไม่มี --reload ส่งออกงานและคัดลอกร่างข้อความก่อนหยุดเซิร์ฟเวอร์ เพราะเซสชันอยู่ในหน่วยความจำ
