# ค้นหาฟอนต์และไล่แก้ชื่อ — 15 ตุลาคม 2026

## ฟอนต์

พิมพ์ในช่อง “ค้นหาฟอนต์” แล้วเลือกจากรายการ รองรับค้นหาบางส่วน ไม่แยกตัวพิมพ์ใหญ่/เล็ก และละเว้นช่องว่าง/ขีด เช่น `th sarabun`, `THSarabunPSK`, `PSK`, `สารบรรณ` การค้นหาไม่เปลี่ยนฟอนต์ที่เลือกเอง หากไม่พบยังคงฟอนต์ปัจจุบัน

เพิ่มชุด 4 ไฟล์จากผู้ร่วมเผยแพร่ SIPA: https://www.f0nt.com/release/13-free-fonts-from-sipa/ ได้แก่ THSarabun.ttf, THSarabun Bold.ttf, THSarabun Italic.ttf, THSarabun Bold Italic.ttf พร้อม DIP&SIPA Font License Agreement.txt โดยคง bytes เดิม ไม่มีการเปลี่ยนชื่อภายในฟอนต์

**THSarabun เป็นชื่อไฟล์ ส่วน THSarabunPSK เป็นชื่อ PostScript ภายในไฟล์เดียวกัน** รายการจึงแสดง `THSarabunPSK (THSarabun)` และรูปแบบหนา/เอียง ค้นหาได้ทั้งสองชื่อ ไม่สร้างฟอนต์ปลอมชื่อ THSarabun และไม่สลับเป็น TH Sarabun New หรือ Sarabun ของ Google โดยอัตโนมัติ แหล่งดาวน์โหลดและ SHA-256 อยู่ใน backend/fonts/THSarabun-source.json

## แก้ชื่อบุคคล

1. เลือกค้นหาและแทนที่ ใส่ชื่อเดิมใน “ค้นหาข้อความ” และชื่อใหม่ใน “แทนที่ด้วย” แล้วกดค้นหา
2. แสดงจำนวนและตำแหน่งที่พบ พร้อมเลือกบรรทัดและเปลี่ยนหน้าให้ ปุ่ม “ก่อนหน้า/ถัดไป” ใช้ตรวจหรือข้ามจุดโดยไม่เปลี่ยน PDF
3. “แทนที่ตำแหน่งนี้” บนผลค้นหา แก้เฉพาะจุดนั้น หรือใช้ “แทนที่จุดนี้ แล้วไปต่อ” เพื่อตรวจตำแหน่งที่เหลือต่อได้โดยไม่ต้องค้นใหม่
4. “แทนที่ทั้งหมด” ทำเป็นคำสั่งเดียว ย้อนกลับด้วย Undo ครั้งเดียวได้ หากจุดใดแก้ไม่ได้จะไม่ commit เอกสารที่แก้ไปบางส่วน
5. หลังแก้ทุกครั้ง ระบบค้นตำแหน่งใหม่จาก PDF รุ่นล่าสุด ใช้ฟอนต์เดิมเป็นค่าเริ่มต้น หรือฟอนต์ที่ผู้ใช้เลือกในแถบขวา

ค้นหาเป็นข้อความตรงตัวภายในบรรทัด แยกตัวพิมพ์ใหญ่/เล็ก ไม่ใช่การระบุตัวบุคคลอัตโนมัติ หากชื่อเดียวกันหมายถึงคนละคน ให้ตรวจทีละจุด ข้อความข้ามบรรทัดและภาพสแกนยังค้นแทนที่แบบนี้ไม่ได้ หากเกิน 2,000 จุดจะปฏิเสธและขอคำค้นเฉพาะขึ้น แทนการแทนที่บางส่วนแล้วแจ้งว่าครบ

ผลทดสอบ: Backend 38 รายการ Frontend 21 รายการ ผ่าน TypeScript และ production build ผ่าน (environment นี้ใช้ `--configLoader runner` เนื่องจาก esbuild อ่าน parent directory ใน sandbox ไม่ได้) ยังไม่ได้ตรวจ browser E2E จริง และยังไม่ใช่ทุกความสามารถของ Adobe Acrobat Pro
